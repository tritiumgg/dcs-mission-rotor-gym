# Approach lanes

**Status:** idea
**Size classes:** all, one shared set of lanes

## Purpose
Fly normal, steep and shallow approaches, with feedback at each gate, like a school's approach checks.

## Location
Not chosen. The runway, or open ground near the field.

## Layout
- A lane per approach type, with gate zones at set heights and distances.

## Player flow
- At each gate, a message says whether the helicopter was high, low, fast or slow.

## Tests
- Script: gate detection and the high/low/fast/slow judgement. Run against the DCS stub.

## Open questions
- Gate heights and speeds per approach type, and whether they vary by helicopter type.
