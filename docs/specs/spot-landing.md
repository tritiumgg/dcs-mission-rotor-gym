# Spot landing

**Status:** idea
**Size classes:** all; the target rings can scale to the type

## Purpose
Touch down on a precise spot, gently.

## Location
Not chosen. Near the fundamentals.

## Layout
- Rings on the ground, made from statics, scored by distance from the centre.

## Player flow
- Touchdown distance from the centre, as a message.
- Firm-landing check (idea): read the vertical speed at touchdown and grade it, from "butter" to "check your spine". This could be a shared feature used by every landing area.

## Tests
- Script: touchdown detection, distance and vertical-speed grading. Run against the DCS stub.

## Open questions
- Whether the firm-landing check runs everywhere or only in landing areas.
- Grading thresholds per type.
