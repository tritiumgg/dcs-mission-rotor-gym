# Low-level navigation

**Status:** idea
**Size classes:** all

## Purpose
Low-level flying and navigation by map and terrain.

## Location
The terrain within about 10 nm of the centre.

## Layout
Three ideas:
- **Valley run:** a timed course through a valley with gate zones. The run fails if the helicopter climbs above a set height above the ground.
- **Checkpoint navigation:** a kneeboard map with checkpoints and no waypoints; the pilot finds each one by map and terrain.
- **Ring course:** gates built from two towers or stacks of containers, flown in order against a timer (see also [slalom](slalom.md)).

## Player flow
- F10 menu: start a course, which starts a timer. Gate checks and a height-above-ground limit.

## Tests
- Script: gate order, height-above-ground checks, timing. Run against the DCS stub.

## Open questions
- Which of the three, if any.
