# Sling loading

**Status:** planned
**Size classes:** loads graded by weight; only types that can sling loads

## Purpose
Pick up an external load, carry it and set it down accurately.

## Location
A pickup pad near the field, with delivery spots of increasing difficulty: an open ring, a [rooftop](rooftops.md), the [oil rig](oil-rig.md), the [ship deck](ship-deck.md), a [confined area](confined-areas.md), a ridge.

## Layout
- A row of cargo at the pickup pad, graded from light to near maximum, each labelled with its weight.
- Delivery rings, scored by distance from the centre.

## Player flow
- F10 menu: spawn a fresh load at a pad (keeps the area clean in co-op), and reset.
- Score delivery distance; detect the load touching down early.
- Brainstorm extras (idea): a sling slalom, flying a load through gates without it touching the ground; stacking containers.

## Tests
- Script: load spawning and naming per player, delivery scoring, reset. Run against the DCS stub.
- In game: which types can sling, the load weights per type, and the hook-up behaviour.
