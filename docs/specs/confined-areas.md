# Confined areas

**Status:** idea
**Size classes:** each clearing labelled with its size in rotor diameters

## Purpose
Land in clearings surrounded by trees or buildings, stepping down from easy to tight.

## Location
Not chosen. Forest edges and villages between the coastal plain and the foothills.
No API can detect trees, so every clearing needs a visual check in game. The "remove scenery objects" trigger can cut a clearing (trees only).

## Layout
- Clearings of several sizes, each labelled, such as "2 D" (twice the rotor diameter).

## Player flow
- F10 menu: smoke at a clearing, and its size.

## Tests
- In game: the actual clearing sizes and obstacles.

## Open questions
- Use natural clearings, or cut them with the trigger.
