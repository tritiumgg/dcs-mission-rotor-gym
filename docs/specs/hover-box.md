# Hover box

**Status:** planned
**Size classes:** one box per class (Small, Medium, Large), side by side

## Purpose
Hold a steady hover over a spot, at a set height, without drifting.

## Location
Within about 2 nm of the spawn, alongside the other fundamentals. Not chosen yet.
Prefer paved or open ground that has been checked in game for trees.

## Layout
- A square per class, marked with cones or tyres, about 1 D on a side (D = the class's largest footprint).
- Brainstorm extra (idea): a "height ladder" of poles or stacked containers at 3, 10 and 25 ft, for holding a hover level with each top.

## Player flow
- F10 menu: start, stop or reset the box for my helicopter.
- A timer counts while the helicopter stays inside the box and within the height band.
- Brainstorm extra (idea): an F10 message with the best time this session, and a drift readout.

## Tests
- Script: in-box and height-band checks, timer start, pause and reset, per-player state. Run against the DCS stub.
- In game: the box size feels right for each class, and the markers are visible from the cockpit.

## Open questions
- Exact location.
- Height band per class, or one band for all.
- How much feedback: a timer only, or drift too.
