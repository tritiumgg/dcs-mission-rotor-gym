# Autorotation lane

**Status:** planned
**Size classes:** all, one shared lane; touchdown scoring can scale to the type

## Purpose
Practise autorotations: hovering autos, straight-in, and 180° autos to a touchdown target.

## Location
Candidates:
- The runway, 07/25.
- The flat coastal plain 2–4 nm west of the planned centre, about 5 m elevation, flat to within 4 m over 1.2 km squares, with no buildings. Trees not checked.

## Layout
- A start gate (altitude and position) and a marked touchdown box.
- Brainstorm extra (idea): a long dirt strip for running-landing style touchdowns.

## Player flow
- F10 menu: start a run. The pilot rolls the throttle off at the start gate.
- Score touchdown distance from the target, and touchdown vertical speed (see the firm-landing idea under [spot landing](spot-landing.md)).
- Brainstorm extra (idea): engine failure on demand, see [engine failure](engine-failure.md).

## Tests
- Script: gate detection, touchdown detection, distance and vertical-speed scoring. Run against the DCS stub.
- In game: the gate altitude for each type, and the surface around the touchdown box.

## Open questions
- Runway or plain.
- Fixed start gates, or an F10 choice of entry (straight-in, 180°, hover).
