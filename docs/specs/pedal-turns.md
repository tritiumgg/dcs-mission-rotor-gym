# Pedal turns

**Status:** planned
**Size classes:** one pad per class

## Purpose
Turn a full 360° in the hover, about the mast and about the nose, while staying over the spot.

## Location
Within about 2 nm of the spawn, with the other fundamentals. Not chosen yet.

## Layout
- A circular pad per class, marked so the pilot can see drift.
- About the nose: a centre marker the nose stays over, with a ring for the tail.

## Player flow
- F10 menu: start a turn, about the mast or about the nose, left or right.
- Measure how long the full turn takes and the maximum drift from the centre.

## Tests
- Script: heading accumulation through 360° in both directions, drift measurement and turn completion. Run against the DCS stub.
- In game: pad sizes, and whether drift scoring feels fair per class.

## Open questions
- Whether the turn rate should be scored, or only drift.
- How to tell the pilot their drift: a message or markers.
