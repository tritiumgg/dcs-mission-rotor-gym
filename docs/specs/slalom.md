# Slalom

**Status:** planned
**Size classes:** one course per class, or gates sized per class

## Purpose
Fly a weaving course through gates, in a low hover or at low level, against the clock.

## Location
Open flat ground. Candidates: near the fundamentals for a hover slalom, or the coastal plain for a faster low-level course. Not chosen yet; trees need a visual check.

## Layout
- Gates of two poles or cones, about 1.5 D wide (D = the class's largest footprint).
- Brainstorm extra (idea): a ring course of gates built from towers or stacked containers, flown in order.

## Player flow
- F10 menu: start the course, which starts a timer.
- Gates are detected by zone. A missed gate adds a penalty; finishing stops the timer.

## Tests
- Script: gate order, missed-gate penalties, finish detection, per-player runs. Run against the DCS stub.
- In game: gate visibility and spacing per class.

## Open questions
- A hover slalom, a low-level course, or both.
- The penalty per missed gate.
